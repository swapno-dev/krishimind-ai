# KrishiMind AI

## Run locally
```
npm install
npm run dev
```
Opens at http://localhost:5173

## Get a live link (no local setup needed)
1. Create a free GitHub account if you don't have one, and a new empty repo.
2. Upload this whole folder to that repo (drag-and-drop on github.com works, or `git push`).
3. Go to https://vercel.com → "Add New Project" → import that GitHub repo.
4. Vercel auto-detects Vite, builds it, and gives you a live URL like `https://krishimind-ai.vercel.app`.
5. Every time you push a change to GitHub, the link updates automatically.

Netlify works the same way at https://app.netlify.com if you prefer that instead.
